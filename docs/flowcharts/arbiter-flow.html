Key Differences from Basic Escrow

  • Timeout refund requires mediator co-signature (refundAfterTimeout) — buyer cannot withdraw alone
  • Dispute paths split into 3 outputs: recipient, treasury, mediator
  • Mediator fee is a runtime argument (per-transaction), not fixed at deploy time
  • If arbiterKey = 0x00...00, dispute paths are unreachable (equivalent to basic escrow)
  • Used as the covenant for jury mode too — the treasury key acts as the "arbiter"
