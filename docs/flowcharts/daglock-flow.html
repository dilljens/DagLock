Constructor Parameters

buyerKey byte[32] Buyer's public key
sellerKey byte[32] Seller's public key
tradeHash byte[32] SHA-256 of swap secret (zeros = no atomic swap)
timeout int Unix timestamp for refund
treasuryKey byte[32] DagLock treasury public key

Output Layout

Every release/swap transaction has exactly 2 outputs:

  • output[0]: Recipient (buyer or seller) — receives inputValue - feeAmount
  • output[1]: Treasury — receives inputValue / 200 (0.5%) as P2PK to treasuryKey

Refund transaction has 1 output (full amount back to buyer, no fee).

Key Rules

  • Fee is hardcoded as inputValue / 200 in all 3 entrypoints
  • tradeHash = byte[32](0) means the swap() path is unreachable (nobody can forge SHA-256(?) = 0)
  • Constructor uses byte[32] (not pubkey) to work around compiler strict typing
