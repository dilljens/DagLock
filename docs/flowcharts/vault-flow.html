DagLock Time-Locked Vault (daglock_vault.sil)

Constructor Parameters

ownerKey byte[32] Owner's public key
timeout int Unix timestamp — withdrawal blocked before this
treasuryKey byte[32] Treasury public key

Output Layout

  • output[0]: Owner — receives inputValue - feeAmount (99.9%)
  • output[1]: Treasury — receives inputValue / 1000 (0.1% protocol fee)

Rules

  • Single spending path with one signature from the owner
  • Withdrawal is blocked before timeout — the covenant checks tx.time >= timeout
  • 0.1% fee (1/1000) vs escrow's 0.5% — vaults have lower fees
  • No emergency recovery — if owner loses key, funds are irrecoverable
