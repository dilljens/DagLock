DagLock Vault Multisig (daglock_vault_multisig.sil)

Constructor Parameters

key1 byte[32] Signer 1 public key (required)
key2 byte[32] Signer 2 public key (zero = unused)
key3 byte[32] Signer 3 public key (zero = unused)
timeout int Unix timestamp
treasuryKey byte[32] Treasury public key

Key Details

  • All non-zero keys must sign — this is N-of-N multisig, not threshold
  • 1-of-1: only key1 set → 1 signature required
  • 2-of-2: key1 + key2 set → 2 signatures required
  • 3-of-3: all 3 keys set → 3 signatures required
  • If a key is zero, the checkSig for that position is skipped
  • 0.1% protocol fee (same as other vault types)

Security Note

This is NOT a threshold multisig (e.g., 2-of-3). It requires all configured keys to sign. If you need M-of-N threshold, the covenant would need to be extended with a counter.
