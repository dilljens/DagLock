Constructor Parameters

beneficiaryKey byte[32] Beneficiary public key (password withdraw destination)
passwordHash byte[32] SHA-256 of the password
timeout int Unix timestamp
treasuryKey byte[32] Treasury public key

Key Difference from Basic Vault

  • Two spending paths instead of one: password OR timeout
  • Password withdraw is restricted to beneficiary address (hardcoded in output script check)
  • Anyone who knows the password can trigger withdrawPassword, but funds always go to beneficiary
  • Timeout path requires owner's signature (same as basic vault)
  • Password is verified on-chain via SHA-256(password) == passwordHash
