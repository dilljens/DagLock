# DagLock

Trustless escrow & atomic swaps on Kaspa L1 via SilverScript covenants.

## Architecture

```
contracts/ (SilverScript) → indexer/ (Rust axum) → API → web/ (React), bot/ (Node.js)
```

## Key Rules

1. Never `.unwrap()` outside `#[cfg(test)]` — panics crash the indexer in production
2. Never hardcode addresses/keys in covenant source — all params via constructor
3. Never skip fee validation in release/swap paths — treasury output must be checked
4. Never change fee denominator (200) without updating ALL paths — hardcoded in compiled bytecode
5. Never expose private keys in bot/CLI/WASM — only unsigned txs assembled
6. Never use non-atomic updates for lifecycle transitions — use `settle_escrow_atomic()`
7. Never skip address validation on create — validate with `validate_kaspa_address()`

## Architecture Patterns

- **One escrow, one UTXO** — isolated cells, no shared contract wallets
- **Trustless by construction** — covenant enforces all rules, no admin keys
- **Proposal before commitment** — negotiate terms, then lock funds
- **UTXO model + covenants** — lock coins in UTXO, spend via covenant rules
- **Three verifier modes**: WrpcVerifier (real node), RestVerifier (REST API), MockVerifier (offline)

## Fee Model

0.5% (value/200) protocol fee to DagLock treasury. Hardcoded in covenant bytecode (`FEE_DENOMINATOR = 200`).

## Testing Patterns

- Covenant tests use `TxScriptEngine` with real Schnorr signatures (no node needed)
- Test files follow domain naming: `daglock_<domain>_tests.rs`
- Response format: `assert!(result.is_ok(), "message: {:?}", result.err())`
- Offer tests create real Offer structs via `insert_offer()` helper
- Auth tests use `MockVerifier` or `SchnorrVerifier` directly
